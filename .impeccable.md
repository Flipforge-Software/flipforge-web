## Design Context

### Users
Flipper Zero owners setting up or repairing a Wi-Fi Devboard connection. They may be comfortable with hardware, but the interface must still work for a first-time user who is troubleshooting under pressure.

### Brand Personality
Mechanical, direct, and trustworthy. The product should feel native to Flipper hardware: compact language, visible system state, and no decorative clutter.

### Aesthetic Direction
Dark, restrained, and utility-led, using Flipforge's orange accent and Flipper type family. Momentum firmware's website is the quality reference. Avoid blocky card grids, generic setup wizards, glossy gradients, and AI-looking decoration.

### Design Principles
- Show one next action at a time and explain physical hardware actions plainly.
- Treat device state as the primary visual information.
- Use open layouts, dividers, and precise spacing instead of cards.
- Keep credentials masked and disclose security behavior near the action.
- Preserve the existing Flipper typography, palette, and compact console language.
